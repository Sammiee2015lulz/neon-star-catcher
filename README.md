# Neon Star Catcher

A fun, cool, neon-styled HTML5 Canvas game!

Catch the falling stars with your glowing paddle to score points. Avoid the bombs!

## How to Play

- Move your mouse left/right to control the paddle
- Or use Arrow Keys / A-D
- Catch yellow stars for +10 points
- Avoid red bombs (or lose a life)
- Miss a star and you lose a life
- 3 lives total
- Speed increases as you score

## High Score

Your best score is saved in the browser (localStorage).

## Run Locally

Just open `index.html` in any modern browser. No server needed!

Or use a simple server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Features

- Neon glow effects
- Particle explosions on catch/hit
- Increasing difficulty
- High score persistence
- Responsive controls (mouse + keyboard)
- Single file, zero dependencies
